# FORMA 序间 · 官山有溪案例版

**在线演示：https://richardli87.github.io/forma-atelier-demo/**

可直接分享链接，无需安装或登录。

面向高端室内设计团队的空间设计 Demo，以官山有溪首层真实平面为依据，呈现东方收藏与意式秩序两种风格的人视及轴侧试生成。

## 演示路线

1. 项目提案：查看原案与实际设计平面。
2. 空间工作台：切换平面、原案、人视及首层轴侧。
3. 风格解读：查看参考出处、材质、家具与光影规则。
4. 方案审阅：并排核对平面、原案和生成结果，记录修改意见。
5. 素材档案：查看五份客户资料的精选页面。

## 当前范围

四张图片为本次使用平面与参考资料实际预生成的试验成果。网页尚未接入实时 AI 服务；修改文字、上传新图或参考图不会自动重新生成。图片存在已记录的桌椅、窗区和跨视图偏差，尚未通过空间精度验收。轴侧为静态图片，不包含可编辑三维模型。

## 素材来源

客户提供：官山有溪效果图设计方案、Rimadesio Presentation、江西谧享家、达普利装饰设计项目案例、私宅设计服务建议书。页面内保留文件与页码出处。家具或品牌来源不等于整个空间属于某位大师的风格。

## 使用与存储

评审、备注与导入素材保存在访问者自己的浏览器中，不会在同事之间同步；可导出备份。

## 项目结构

- `dist/`：网页、样式、交互与全部案例图片。
- `.github/workflows/static.yml`：GitHub Pages 自动发布流程，发布目录为 `dist`。

推送到 main 后自动检查脚本并更新在线演示。
